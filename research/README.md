# Strategy curriculum

`curriculum.json` is an attributed, versioned collection of twenty strategy fixture families. It contains original summaries and controlled variations, not copied guide passages. Each family has a permanent train/validation/test partition.

The catalogue is a specification for positions, not proof that a move is best. A family only becomes a training demonstration after a concrete, reproducible legal position is linked, candidate actions are checked, and the user reviews the strategic preference. Never fill missing hidden information from a later replay frame.

The supplied PDF files and extracted page chunks are stored in ignored local `data/competitive/`. Capture date is distinct from section publication date. The guides contain historical and prospective lists; use the designated compatible deck version for each example.

Sources:

- The Ultimate Crustle Guide, Rahul Reddy and Carter Malnaik; private user-supplied PDF, 32 pages, SHA256 `f48de6a46753ee83b3b88be698c513fb7186d85b5ad294e4fc9fe824912327f7`.
- How to Play Crushing Hammer Dragapult, Andrew Hedrick; private user-supplied PDF, 55 pages, SHA256 `74f84b68a7afb2825c3da2553a099ad94fa6eaf5703a6afc25bfc329565bc4c2`.

Matchup percentages in those sources are author assessments. They are not supervised outcome labels or measured results from this project.
